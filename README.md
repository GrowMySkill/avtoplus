# Авто Плюс

Адаптивный лендинг и устанавливаемое веб-приложение (PWA). Статический HTML/CSS/JavaScript, без зависимостей для сборки.

## Запуск

`npm run dev` — локальный сервер на http://localhost:4173.

`npm run check` — проверка синтаксиса JavaScript.

Корень опубликованного сайта — `dist/`. PWA требует HTTPS или localhost. После первого открытия страница и фотографии доступны офлайн. Внешние маршруты и звонки зависят от возможностей устройства и подключения.

## Данные

Единственный источник сведений о бизнесе — `data/test.json`, полученный из карточки https://2gis.ru/gelendzhik/firm/70000001065327447. Опубликованная копия — `dist/business.json`. Названия услуг и категорий сохранены; группы созданы для навигации. Цены, график работы, гарантии, наличие товаров и неподтверждённые преимущества не добавлены. Положительные отзывы дословно перенесены из карточки 2ГИС; авторы, даты и источник сохранены в `data/reviews.json`.

Фотографии взяты из галереи той же карточки. Источники перечислены в `data/photos.json`. На сайте есть ссылка и атрибуция 2ГИС. Новый наборный знак в шапке — оформление демо, не заявление об официальной айдентике.

## Возможности

- Поиск услуг с обработкой пустого результата, группы с раскрытием.
- Фильтры категорий товаров.
- Галерея с увеличением, стрелками и закрытием Escape.
- Мобильное меню и закреплённые кнопки звонка и маршрута.
- Web App Manifest, иконки и Service Worker; установка в поддерживаемом браузере.
- Предупреждение о демо внизу страницы.

Форма заявки и сервер приёма данных отсутствуют: основной контакт — подтверждённый телефон компании.

В верхней части страницы размещён виджет официального конструктора карт 2ГИС. Центр и отметка соответствуют координатам карточки компании. Карта требует подключения к интернету.
