# Дизайн Авто Плюс

Сценарий: посетитель выбирает направление (магазин или сервис), находит категорию или услугу, звонит или открывает маршрут в 2ГИС. Основной призыв — звонок на подтверждённый номер.

Композиция: первый экран с реальным сервисным боксом → магазин → фильтруемые категории → поиск услуг → галерея → контакты → демо-предупреждение. Цены и рейтинги не используются. По запросу добавлена отдельная подборка реальных положительных отзывов с атрибуцией 2ГИС.

Сдержанная автомобильная эстетика: крупная типографика, фотографии реального бизнеса, тонкие разделители, красный акцент по вывеске. Фотографии не заменяются стоковыми или сгенерированными изображениями.

Шрифт Manrope: 700–750 для заголовков, 400–650 для основного текста, резерв Arial/sans-serif. Google Fonts загружается при наличии сети; офлайн используется резервный шрифт. Заголовки 46–78 px на первом экране, секционные 36–56 px. Базовая сетка: 4/8 px; углы 3–5 px, без декоративных теней на карточках.

Рассчитанный контраст: белый / CTA — 4,58:1; основной текст / фон — 14,76:1; вторичный текст / фон — 5,06:1; вторичный текст / поверхность услуг — 4,65:1.

## Взаимодействия и доступность

Кнопки не меньше 44 px на телефоне. Раскрывающиеся группы используют details/summary; фильтры — aria-pressed; поиск — именованное поле и статус результатов; фотографии — modal dialog с клавиатурной навигацией. Есть переход к основному содержимому и видимый фокус. Все фотографии снабжены alt-текстом. Анимация отключается через prefers-reduced-motion.

На ширине до 767 px: меню-кнопка, одна колонка, фиксированная нижняя панель звонка и маршрута, safe-area для iPhone. На планшетах сохраняется двухколоночный первый экран. Текстовые блоки не имеют фиксированной высоты.

Не использовать: неподтверждённые преимущества, искусственные скидки, фальшивые отзывы, выдуманные цены, формы с неработающей отправкой и автоматические всплывающие окна.
